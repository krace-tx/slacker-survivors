# Cozy Studio 2.5D 测试场景 (`cozy_studio`)

> **测试定位**：验证 **「高精二次元阁楼建模场地（Blender 5.2 导出 `55,392` 面 `.glb`）+ 3D 暖色赛璐璐水彩与暖棕钢笔线稿管线 + 2D 3 视图序列帧纸片人角色 + 三段式跟随同面相机」** 的端到端融合效果。

---

## 一、 核心验证维度（2.5D 协调五件套）

1. **高挑精模二次元阁楼场地（`8.80m × 7.80m × 4.15m`，`mdl_cozy_studio_room.glb`）**：
   - 告别低矮简陋几何块：包含 `4.15m` 高挑护墙板阁楼墙、外露原木斜撑顶梁、法式多格高窗（窗外花箱桃粉花簇 + 正弦褶皱束腰白纱帘）、`3.18m` 双跨拱顶书柜与黄铜滑梯、开放胡桃木黄铜咖啡悬架与双头复古意式咖啡机、曲面细分簇绒贵妃沙发、麻花编织圆地毯、酣睡橘猫与黄金角叶序弧面绿植（共 `724` 部件、`55,392` 面，结构质检零错误）。
2. **二次元暖调赛璐璐水彩材质 + 屏幕空间暖棕钢笔线稿（`shd_cozy_studio_anime_env.gdshader` + `shd_cozy_studio_anime_outline.gdshader`）**：
   - 将 3D 房间表面自动转换为 **二阶暖色赛璐璐明暗阶梯（暖杏玫瑰色暗部取代灰黑物理漫反射）+ 世界空间水彩纸纹与橡木笔触**；
   - 挂载平面距离自适应的 **暖深棕（`#4E3121`）二次元钢笔线稿后处理**，并通过粗糙度特征签名（`ROUGHNESS = 0.99`）精准屏蔽 2D 角色立绘，杜绝双层描边。
3. **三段式丝滑跟随与视平面平行相机（`CozyCameraRig3D`）**：
   - 采用 `CozyCameraRig3D -> YawPivot -> PitchPivot -> MainCamera` 四层解耦结构，内置 **圆形微死区（`0.22m`）+ 速度前瞻（`Look-Ahead`）+ 阁楼软边界夹取 + 帧率无关指数平滑**。
   - 支持 `Q / E` 丝滑旋转镜头偏航角，并通过 `yaw_changed` 信号驱动全场 2D 立牌同步对齐 Y 轴水平视平面（**View-Plane Parallelism**）。
4. **正/侧/背 3 视图图集 UV 序列帧动画（`spr_cozy_studio_slacker_sheet.png` + `CozyStandeeActor3D`）**：
   - 标准 **6 行 3 视图等网格图集（`4×6`）** 配合 **相机相对施密特迟滞解算** 与相位连续迈步循环，地面 3D 方向长阴影随正/侧/背迈步序列帧实时变化。
5. **体积空气感粘合层**：
   - 渲染优先级高于线稿层的法式高窗丁达尔暖阳光束（[`shd_cozy_studio_sunbeam.gdshader`](assets/shaders/shd_cozy_studio_sunbeam.gdshader)）与 3D 阳光浮尘粒子（`GPUParticles3D`）。

---

## 二、 交互操控说明

- **`WASD` / 方向键**：控制 2D 摸鱼少女在 3D 阁楼内播放 **正/侧/背 3 视图手绘走路循环**
- **`Q` / `E`**：连续丝滑旋转镜头视角（角色自动流转正/侧/背 3 视图并始终与镜头保持完美同面）
- **`F`（或顶部按钮）**：切换 `近景丝滑跟随` / `全景箱庭固定` 相机模式
- **`鼠标滚轮`**：丝滑推拉镜头远近（Zoom）
- **`1` / `2` / `3`（或顶部按钮）**：切换 `24.5° 长焦透视` / `正交等轴箱庭` / `68° 广角对比`
- **`L` / `G` / `R`**：切换 `午后暖阳 / 傍晚台灯`、开关 `二次元赛璐璐+线稿滤镜（实时对比原始3D）`、一键复位
