# Cozy Studio 2.5D 测试场景 (`cozy_studio`)

> **测试定位**：验证 **「高精二次元阁楼建模场地（Blender 5.2 导出 `55,392` 面 `.glb`）+ 3D 暖色赛璐璐水彩与暖棕钢笔线稿管线 + 2D 正/侧/背 3 视图（待机/走路/坐姿 `4×9` 图集）纸片人 + 3D 家具兼容交互系统 + SVG 治愈手账风 UI」** 的端到端融合效果。

---

## 一、 核心验证维度（2.5D 协调六件套）

1. **高挑精模二次元阁楼场地（`8.80m × 7.80m × 4.15m`，`mdl_cozy_studio_room.glb`）**：
   - 包含 `4.15m` 高挑护墙板阁楼墙、外露原木斜撑顶梁、法式多格高窗、`3.18m` 双跨拱顶书柜与黄铜滑梯、开放胡桃木黄铜咖啡悬架与双头意式咖啡机、曲面细分簇绒贵妃沙发、麻花编织圆地毯、酣睡橘猫与黄金角叶序弧面绿植（`724` 部件、`55,392` 面）。
2. **二次元暖调赛璐璐水彩材质 + 屏幕空间暖棕钢笔线稿 + 邻近交互呼吸高光**：
   - 二阶暖色赛璐璐明暗阶梯（暖杏玫瑰色暗部）+ 局部台灯 `Forward+` 零花块柔光衰减 + 家具独立暖金 Fresnel 呼吸边缘高亮（`interact_highlight`）；
   - 挂载平面距离自适应的 **暖深棕（`#4E3121`）二次元钢笔线稿后处理**，通过粗糙度特征签名（`ROUGHNESS = 0.99`）精准屏蔽 2D 角色立绘。
3. **三段式丝滑跟随、视平面平行与箱庭剖面墙动态消隐（`CozyCameraRig3D` + `CozyStudioStage3D`）**：
   - 支持圆形微死区（`0.22m`）+ 速度前瞻（`Look-Ahead`）+ 阁楼软边界夹取 + 帧率无关指数平滑，长按 `Q / E` 丝滑旋转镜头偏航角并保持全场 2D 角色视平面平行；当镜头转入北墙或西窗墙背侧时自动触发箱庭剖面墙消隐，保障 360° 多角度观察零遮挡。
4. **正/侧/背 3 视图 × 待机/走路/坐姿 9 行图集与铅垂深度防穿模（`CozyStandeeActor3D`）**：
   - 标准 **9 行等网格图集（`4×9`，`spr_cozy_studio_slacker_sheet.png`）** 覆盖正/侧/背待机、走路与无椅悬空坐姿，同伴角色采用高清立绘微呼吸（`spr_cozy_studio_partner_idle.png`）；
   - [shd_cozy_studio_standee_2d.gdshader](assets/shaders/shd_cozy_studio_standee_2d.gdshader) 内置观察空间铅垂深度补偿（`tilt_depth_comp` + `seat_depth_pull`），彻底消除后仰纸片贴墙削头或入座 3D 椅背/沙发穿模。
5. **四大 3D 家具跨维兼容交互系统（`CozyInteractOverlay` + `CozyStudioStage3D`）**：
   - **右后咖啡吧台**：走近高亮意式双头咖啡机 + 弹出世界投影 SVG `[E] 冲泡拿铁` 胶囊 + 触发角色开心跃动、泵压高频微震、双头喷嘴奶白蒸汽粒子（`fx_cozy_studio_steam_puff.svg`）与飘浮拿铁香气泡；
   - **左后手绘屏工位 / 右前贵妃沙发**：点按 `[E]` 抛物线小跳入座 / 窝进沙发（3D 转椅与沙发靠垫受迫下陷回弹，转椅附带摸鱼微旋，支持长按 `Q / E` 360° 环绕观察正/侧/背 3 视图坐姿）；
   - **窗边蒲团酣睡橘猫**：走近高亮橘猫，点按 `[E]` 触发角色开心跃动 + 3D 橘猫 Q 弹挤压舒展 + 幸福呼噜微颤 + 飘浮 SVG 粉桃爱心气泡（`ui_cozy_studio_heart_bubble.svg`）。
6. **体积空气感粘合层与 SVG 治愈手账风无框 UI**：
   - 法式高窗丁达尔暖阳光束与浮尘粒子，配合纯矢量 SVG 九宫格手账木牌、实体按键胶囊与 3D 投影交互标签。

## 二、 交互操控说明

- **`WASD` / 方向键**：正/侧/背 3 视图序列帧走动（入座状态下按方向键自动轻跳起身）
- **点按 `E` / `Space` / 鼠标点击悬浮胶囊**：触发当前高亮 3D 家具互动（冲泡拿铁 / 入座工位或沙发 / 撸橘猫 / 起身）
- **长按 `Q` / `E`**：连续丝滑旋转镜头视角（入座时亦可 360° 环绕观察正/侧/背坐姿而不误触起身）
- **`F` / `1·2·3` / `L` / `G` / `R` / 滚轮**：切换跟随/全景、长焦/正交/广角、暖阳/暮色台灯、赛璐璐线稿对比、复位与推拉特写
